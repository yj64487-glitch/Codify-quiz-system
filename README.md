
# 🎯 Codify Quiz System

> An interactive and dynamic online quiz management system developed using JSP, Servlets, Java, and MySQL.

---

## 🚀 Project Overview

Codify Quiz System is a web-based application designed to conduct online quizzes efficiently.  
The system provides a secure and user-friendly platform for students and administrators to manage quizzes, track scores, and analyze performance.

---

## ✨ Features

### 👨‍🎓 User Module
- User Registration & Login
- Attempt Multiple Quizzes
- View Scores & Performance
- Quiz History Tracking
- Profile Management

### 👨‍💼 Admin Module
- Admin Dashboard
- Add/Edit/Delete Questions
- Manage Users
- Quiz Analytics
- Leaderboard Management
